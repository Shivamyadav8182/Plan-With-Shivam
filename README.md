# Plan With Shivam 🌍

A responsive travel destination web application built with React.js.  
The project displays popular tourist destinations with images, descriptions, prices, and an option to remove destinations from the list.

## 🚀 Live Demo

[View Live Website](https://shivamyadav8182.github.io/Plan-With-Shivam/)

## 📌 About The Project

Plan With Shivam is a beginner-friendly React project created to practice core React concepts such as components, props, state, event handling, and array methods.

Users can explore different travel destinations and remove destinations they are not interested in.

## ✨ Features

- 🌍 Displays multiple travel destinations
- 🖼️ Destination images
- 💰 Shows tour prices
- 📝 Destination descriptions
- 🔍 Read more functionality
- ❌ Remove unwanted destinations
- 📱 Responsive layout
- ⚛️ Built with reusable React components
